## Ручной регрессионный чек-лист (обязателен перед «готово»)

Запуск: `npm run dev:staging` (порт 3002).

### Intro (`BlueNestLanding`)
- Открывается без ошибок.
- Переход на «Категории».
- Открыть/закрыть чат (кнопка/аватар).

### Categories (`CategoriesGrid`)
- Все изображения категорий грузятся (нет пустых/битых карточек).
- Hover-анимации карточек и кастомный курсор работают на десктопе.
- Enter/Space по карточке открывают категорию.
- Навигация назад на интро.
- Мобилка (≤768): верхнее меню и нижняя навигация отображаются, кликаются.

### Category (`CategoryView`)
- При первом входе возможна догрузка: отображается «Загрузка значков…», потом список появляется.
- Если имитировать ошибку сети: появляется сообщение + кнопка «Повторить».
- Открытие значка из списка.
- «Назад» возвращает на категории.

### Badge (`BadgeView`)
- Контент/картинки/кнопки уровней работают.
- Переход на уровень (если есть).
- «Назад» возвращает на категорию.

### BadgeLevel (`BadgeLevelView`)
- Переключение уровней.
- «Назад» возвращает на значок.

### AboutCamp (`AboutCampView`)
- Открывается и закрывается без поломок.

### Deep-links / параметры URL
- `?view=category&categoryId=1` открывает категорию и подгружает значки.
- `?view=badge&badgeId=1.15` открывает значок (лениво догружается).
