Оглавление книги «Вожатификатор» для раздела в личном кабинете.

Файл: vozhatifikator-toc.json

Формат — JSON-массив объектов с полями:
  "title" — название главы или раздела (строка);
  "page"  — номер страницы в итоговом PDF (число).

Пример:
[
  { "title": "Начало", "page": 1 },
  { "title": "Глава 1. Как всё начиналось", "page": 5 },
  { "title": "Глава 2. Бросвящение", "page": 12 }
]

После редактуры (этап 1.3): откройте финальный PDF, запишите номер страницы начала каждой главы/раздела и заполните этот файл. Приложение подхватит обновлённый файл без правок в коде.

Вариант B (список → JSON): если удобнее передать список глав, создайте текстовый файл (одна строка на главу, формат «Название | номер_страницы»). Пример: vozhatifikator-toc-list.example.txt. Затем выполните:
  node scripts/vozhatifikator-toc-from-list.mjs public/ваш-файл.txt
Скрипт запишет результат в vozhatifikator-toc.json.

Имя PDF в public/: «Вожатификатор. Главная книга Стёпы 2019.pdf» (или обновите константу VOZHATIFIKATOR_PDF_FILE в ProfileView.tsx при смене имени файла).
