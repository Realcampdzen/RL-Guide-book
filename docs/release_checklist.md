# 🎉 Чек-лист Открытого Бета-Релиза и Публикации

Этот чек-лист поможет вам ничего не забыть перед тем, как вы нажмёте кнопку "Опубликовать".

## Шаг 1: Инфраструктура
- [ ] Отработал ли GitHub Actions / Vercel пайплайн и собран ли проект из ветки `main`?
- [ ] Бекенд запущен и отвечает (базы Supabase и/или Python FastAPI)?
- [ ] Открывается ли ссылка в инкогнито браузере без белого экрана?

## Шаг 2: Проверка Метаданных (Open Graph)
- [ ] Скиньте URL сайта к себе в "Избранное" ВКонтакте или Telegram.
- [ ] *Проверочный вопрос:* Появилась ли обложка и красивый заголовок `Путеводитель Реального Лагеря - Открытая Бета`?
- [ ] *Заметка:* Если картинка не подтягивается, ВКонтакте позволяет очистить кэш ссылок через [pages.clearCache](https://vk.com/dev/pages.clearCache).

## Шаг 3: Проверка Критических Сценариев пользователя
- [ ] Пользователь может зайти под Гостем ("Пропустить") и полистать 3D-значки.
- [ ] При нажатии "Войти" рендерится окно авторизации.
- [ ] НейроВалюша загружается в фоне (или по кнопке) и не ломает UI.
- [ ] Кабинет не выдает 500 ошибку при первой загрузке (если токен пуст).

## Шаг 4: Пост
- [ ] Перечитайте черновик.
- [ ] Убедитесь, что ссылка стоит в начале или в середине поста (чтобы обложка 100% прикрепилась).
- [ ] Проверьте, что в посте есть призыв писать о багах в конструктивном ключе (мы же на стадии Beta!).

**🚀 Если везде галочки — смело релизте!**
