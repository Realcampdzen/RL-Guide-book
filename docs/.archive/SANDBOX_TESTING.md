# Песочница для тестирования

Инструкция по использованию блоков песочницы в личном кабинете для тестирования механик: разблокировка бота, подтверждение значка, план, входящие заявки.

## Включение песочницы

Блоки песочницы видны:
- в режиме разработки (`npm run dev`), или
- при `?sandbox=1` в URL (например: `https://.../RL-Guide-book/#/profile?sandbox=1`), или
- при роли **Разработчик** (developer) — песочница доступна всегда, в т.ч. на проде.

## 1. Разблокировка бота

1. Зайди в профиль, блок «Разблокировать бота».
2. Нажми «Запросить код в Telegram» — скопируй `deviceId` из ссылки или возьми из блока «Сгенерировать код» (он подставляется автоматически).
3. В блоке «Сгенерировать код подтверждения» введи секрет (AUTH_GENERATE_SECRET из .env), нажми «Сгенерировать».
4. Скопируй код и вставь в поле «Введите код» в блоке «Разблокировать бота».
5. Нажми «Подтвердить» — чат разблокируется.

## 2. Подтверждение значка (proof)

1. Добавь значок в путь, нажми «Подтвердить» у уровня.
2. Заполни форму (опыт, влияние, ссылка) и нажми «Отправить в Telegram».
3. Evidence сохранится локально, уровень остаётся «в пути».
4. В блоке «Dev: быстрые одобрения» появится этот уровень.
5. Нажми «Одобрить» — уровень станет достигнутым.

## 3. План значка

1. Нажми «Составить план» у уровня, заполни контекст, получи план.
2. Отправь план в Telegram (кнопка в модалке).
3. В модалке плана нажми «Вожатый утвердил» — план будет отмечен как одобренный.

## 4. Входящие заявки

1. В блоке «Входящие заявки» введи секрет (TELEGRAM_WEBHOOK_SECRET или VK_WEBHOOK_SECRET из .env).
2. Нажми «Обновить» — загрузятся последние события `confirmation_requested` (заявки из TG/VK).
3. Позволяет видеть, что пришло после отправки пользователем в мессенджер.

## 5. Роль «родитель» и блок «Для родителей»

Где смотреть и как тестировать родительский функционал (документы/даты/цены, программа смены, бронирование, значки ребёнка, маршрут развития):

1. **Открой профиль** — внизу экрана нажми **«Мой путь»** (иконка человека со стрелкой).
2. **Включи песочницу** — запусти приложение через `npm run dev` или добавь в URL `?sandbox=1`.
3. **Переключи роль на «Родитель»** — вверху профиля появится полоска «Песочница: роль для теста». В выпадающем списке выбери **«Родитель»** — под паспортом появится блок **«Для родителей»**.
4. В блоке «Для родителей»:
   - **Документы, цены, даты смен** — данные из `public/ai-data/camp-facts.json` (даты, стоимость, список документов, контакты).
   - **Забронировать путевку** — переход в форму записи.
   - **Программа смены** — карточки по дням из `public/ai-data/camp-program-template.json` (переключатель 9 / 21 день).
   - **Значки моего ребёнка** — модалка с вводом кода привязки и списком значков.
   - **Предложить маршрут развития для ребёнка** — форма и отправка в Telegram организатору.

Чтобы снова видеть профиль как участник, выбери в выпадающем списке **«Участник»**.

**Через бэкенд (реальные коды):** в песочнице открой «Код» → выбери роль (Участник, Родитель, Вожатый, Старший Вожатый, Разработчик; роль «Путешественник» в панели генерации не предлагается — verify не выдаёт доступ к чату для неё), введи deviceId и AUTH_GENERATE_SECRET → сгенерируй код. Затем «Разблокировать бота» → введи код и подтверди — роль сохранится с бэкенда.

## 6. Роль «Разработчик» и «Старший Вожатый», отряд вожатых

- **Разработчик (developer):** в выпадающем списке ролей в песочнице выбери «Разработчик». Песочница и все служебные панели (Код, Заявки, Бэкап, переключатель ролей) будут видны всегда, даже без `npm run dev` и без `?sandbox=1`. Удобно для тестирования на проде под своей учёткой.
- **Старший Вожатый (руководитель смены, shift_leader):** выбери «Старший Вожатый». Под селектом ролей отображаются две строки: крупно «Старший Вожатый», мелко «руководитель смены». В профиле появится блок **«Отряд вожатых»**: можно создать отряд (название), получить код и ссылку приглашения, копировать их и отправлять вожатым. Вожатый (роль «Вожатый») не может создавать отряд, но может **войти в отряд по коду** (поле «Войти в отряд вожатых по коду» в том же блоке) или по ссылке (параметр `?counselor_squad=...` в URL).
- **Панель «Сгенерировать код»:** в списке ролей 5 вариантов (Участник, Родитель, Вожатый, Старший Вожатый, Разработчик; без «Путешественник»), т.к. верификация кода для роли traveler не даёт доступа к чату (CHAT_ALLOWED_ROLES на бэкенде).

## Переменные окружения

- `AUTH_SECRET` — для HMAC кодов верификации (скрипт и verify-code API).
- `AUTH_JWT_SECRET` — для JWT (тот же в cf-api).
- `AUTH_GENERATE_SECRET` — для вызова POST /api/auth/generate-code (можно совпадать с TELEGRAM_WEBHOOK_SECRET).
- `TELEGRAM_WEBHOOK_SECRET` — для GET /api/webhook/confirmation-events.
- `CHAT_MESSAGES_PER_DAY` — лимит сообщений в день для чата (по умолчанию 20). Используется в GET `/api/chat/limits`; фронт отображает значение в подсказке «Сообщений в день: N» под полем ввода.
