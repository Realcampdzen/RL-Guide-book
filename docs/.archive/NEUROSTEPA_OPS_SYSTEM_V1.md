# NEUROSTEPA_OPS_SYSTEM_V1.md

Операционная система НейроСтёпы v1 (стартовый рабочий контур).

## 1) Миссия

Сделать НейроСтёпу не просто ассистентом, а операционным слоем Путеводителя:
- быстрее коммуникации,
- выше качество ответов,
- меньше рутины у команды,
- прозрачный цикл улучшений.

---

## 2) Jobs v1 (минимальный набор)

## J1 — discussion-replies-daily
**Цель:** качественные ответы в обсуждениях TG под постами.

- Вход: новые посты/комментарии, контекст треда.
- Выход: 1 уместный комментарий на пост + предметные ответы в ветке.
- DoD: нет дублей/самоответов, стиль соблюдён, оффтоп обработан корректно.
- KPI: replies, продолжение диалога, отсутствие конфликтных ответов.

## J2 — parent-faq-intake
**Цель:** быстро и точно закрывать родительские вопросы.

- Вход: FAQ-вопросы, спорные кейсы.
- Выход: короткие точные ответы + маршрутизация к организаторам при переменных данных.
- DoD: факты точны, есть safety-оговорка по цене/условиям.
- KPI: время ответа, снижение повторных уточнений.

## J3 — approvals-assistant
**Цель:** помогать staff с обработкой заявок/апрувов.

- Вход: заявки/пруфы/контекст роли.
- Выход: черновик решения + аргументация + следующий шаг.
- DoD: нет автопринятия без человека, только decision-support.
- KPI: скорость обработки inbox, консистентность решений.

## J4 — content-distill
**Цель:** превращать длинные тексты/исследования в рабочие SMM-юниты.

- Вход: статьи, тезисы, заметки.
- Выход: инсайты, шаблоны комментариев, CTA-блоки.
- DoD: 1 пример -> 1 вывод, без “этикеточных” списков.
- KPI: применимость в бою, отклик в обсуждениях.

## J5 — weekly-rollup
**Цель:** еженедельная ретроспектива и патч процессов.

- Вход: логи недели, реакции, KPI.
- Выход: 3 сработавших паттерна, 3 проблемы, 3 патча на неделю.
- DoD: изменения зафиксированы в docs и готовы к запуску.
- KPI: устойчивый рост метрик неделя к неделе.

---

## 3) Ритм выполнения

### Ежедневно
- Утро: план ответов и фактчек.
- День: посты/обсуждения/FAQ.
- Вечер: мини-ретро и патч формулировок.

### Еженедельно
- Rollup: анализ KPI + обновление шаблонов/правил.

## 5) Guardrails

- По цене/условиям: финальное подтверждение у организаторов.
- По спорным фактам: эскалация, а не выдумка.
- В обсуждениях: один триггер -> один ответ.
- По стилю: короткие абзацы, живой язык, 1 пример -> 1 вывод.

---

## 6) План запуска v1 (7 дней)

### День 1
- Подтвердить jobs и KPI.
- Запустить J1/J2 в рабочем режиме.

### День 2–3
- Подключить J4 (дистилляция входящих текстов).
- Зафиксировать первые патчи шаблонов.

### День 4–5
- Подключить J3 (assistant для approvals, как decision-support).
- Проверить стабильность форматов ответов.

### День 6–7
- Провести J5 weekly-rollup.
- Обновить правила/шаблоны на основе факта.

---

## 7) Критерий успеха v1

Через 7 дней система должна показывать:
- стабильный и узнаваемый тон,
- меньше ручного хаоса,
- выше скорость и качество ответов,
- прозрачный цикл улучшений без “ручного геройства”.
