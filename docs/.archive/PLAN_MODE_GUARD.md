# Plan Mode Guard — защита от устаревших планов

## Проблема

Plan Mode в Cursor может циклически предлагать планы по уже выполненным задачам (например, `proof_questionnaire_restoration`, `onboarding_hints`). Это приводит к повторным попыткам Build без необходимости и риску перезаписи уже работающего кода.

## Правило для агентов

**Перед Build / выполнением плана — всегда проверять [ROADMAP_2026.md](ROADMAP_2026.md):**

- Если задача из плана помечена **Done** в ROADMAP — **не выполнять план**, не нажимать Build.
- Текущий фокус — раздел «Где мы сейчас» и пункты In progress / Not started.
- Устаревшие планы — игнорировать.

## Известные устаревшие планы (ручная очистка)

Планы Cursor хранятся в пользовательской папке: `c:\Users\<user>\.cursor\plans\` (вне репозитория).

Следующие планы можно безопасно удалить или архивировать:

| План | Статус | Действие |
|------|--------|----------|
| `proof_questionnaire_restoration_*.plan.md` | Done в ROADMAP | Удалить или архивировать |
| `vision_refinement_plan_*.plan.md` | Реальный Дневник, Совет Лагеря — Done/частично Done | Удалить или архивировать |
| `onboarding_hints_*` (если уже Done) | Сверять с ROADMAP | Удалить если Done |
| `openclaw_*` (если уже Done) | Сверять с ROADMAP | Удалить если Done |
