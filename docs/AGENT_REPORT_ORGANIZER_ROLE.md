## 3. Кто такой агент

- **Имя/тип:** Auto (agent router, AI coding assistant в Cursor)
- **Режим:** Agent mode — выполняет задачи по плану, редактирует файлы, запускает проверки
- **Инструменты:** чтение/запись файлов, поиск по коду, терминал, todo-трекер
- **Контекст:** workspace rules (Taskmaster, cursor_rules, self_improve), приложенный план target_roles_rbac
