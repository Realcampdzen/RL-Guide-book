## 2. Контекст (что уже есть)

- **P1-05 (done):** forced traveler убран — роль берётся из JWT.
- **Unlock panel** (`openBubble === 'bot'`) в ProfileView: код верификации вводится, вызывается `POST /api/auth/verify-code`, `setAuth(data)` устанавливает роль.
- **Проблема #1:** После успешной верификации код панель **не закрывается** (`setOpenBubble(null)` не вызывается) и нет success-toast/hint → пользователь не понимает что успех.
- **Проблема #2:** Заголовок панели «Разблокировать бота» — вводит в заблуждение. Пользователь разблокирует роль (участника/вожатого), а не только бота.
- **Проблема #3:** После unlock нет подсказки/CTA «Войди в отряд по коду».
- **Smoke-сценарий 2 (заявки):** `ProfileView` → панель входящих заявок → approve. Визуально проверить что approve/reject работает.
- **Smoke-сценарий 3 (parent snapshot):** ProfileView → создать код/QR (кнопка «Создать код для родителя») → read-only вид. Визуально проверить flow.
