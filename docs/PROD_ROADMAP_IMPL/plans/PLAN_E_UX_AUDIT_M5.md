## 4. Блоки аудита

### Блок 1 — Роли (5 сценариев)

Для каждой роли пройди путь и сделай скрин каждого ключевого экрана.

#### 1A — Participant (основной путь)
1. Открой `https://realcampdzen.github.io/RL-Guide-book/`
2. Лендинг → убедись что он загружается, выглядит нормально
3. Перейди в категории бейджей → все 14 категорий отображаются?
4. Открой детейл любого бейджа → описание, кнопка "Подать заявку"
5. Подай заявку на бейдж (или попробуй)
6. Перейди в профиль → кабинет участника
7. Проверь вкладку "Коллекция" — уровни, бейджи
8. Вкладка "Мои заявки" — статусы чипов (pending/approved/rejected)
9. Если есть rejected — видна ли причина отказа под чипом?
10. Попробуй вызвать Валюшу из профиля

**Скрины:** лендинг, категории, детейл бейджа, профиль (кабинет), коллекция, заявки

#### 1B — Parent (read-only)
1. Залогинься как parent
2. Открой кабинет — видны ли данные ребёнка?
3. Попробуй нажать кнопки которые должны быть заблокированы (подать заявку, редактировать)
4. Убедись что `403` или кнопки просто не рендерятся
5. ImageSourceBlock — появляется ли у parent? (Не должен)

**Скрины:** кабинет parent, попытка staff-действия

#### 1C — Counselor
1. Залогинься как counselor
2. Перейди в Squad Corner → отряды, участники
3. Открой Inbox заявок → список pending
4. Approve одну заявку — обновляется ли UI оптимистично?
5. Reject другую с причиной → введи текст причины
6. Посмотри как отображается resolved заявка (должна исчезнуть/быть серой если TTL не истёк)

**Скрины:** squad corner, inbox, форма reject с полем причины

#### 1D — Shift Leader
1. Залогинься как shift_leader
2. Проверь расширенный доступ — все ли отряды видны?
3. Попробуй `POST /api/badges/requests/cleanup` через UI или DevTools
4. Council dashboard — отображается?

**Скрины:** дашборд shift_leader, расширенные возможности

#### 1E — Developer
1. Залогинься как developer
2. Открой DevPanel (если есть в UI)
3. Code generation — работает?
4. Все staff-функции доступны?

**Скрины:** dev-панель, code gen

### Блок 2 — UX-баги глазами

Проверь каждый пункт и поставь статус: ✅ OK / ⚠️ Minor / ❌ Bug

| # | Что проверить | Ожидание |
|---|---------------|----------|
| U1 | Чипы статусов заявок: цвет текста + border | У каждого статуса свой цвет (не просто border, но и текст) |
| U2 | ImageSourceBlock: кнопка "Обработать ИИ" во всех 6 контекстах | Отображается везде где canEdit=true |
| U3 | Auto-sync при открытии профиля | Если есть новые approved уровни → celebration tutorial появляется |
| U4 | Reject reason под чипом | Серый текст "Причина: [текст]" с ellipsis если длинный |
| U5 | Pending badge count в чате | Спроси Валюшу "сколько у меня заявок" — знает ли она? |
| U6 | Длинный reject reason (>100 символов) | Обрезается + title с полным текстом при hover |
| U7 | Навигация между вкладками профиля | Переключение плавное, без мерцания |
| U8 | Загрузка данных | Есть ли лоадеры/скелетоны? Или пустые вспышки? |

### Блок 3 — Мобильная адаптация

Уменьши окно браузера до **375px** (или используй DevTools Mobile mode → iPhone SE).

Проверь на каждом ключевом экране:

| Экран | Что смотреть |
|-------|-------------|
| Лендинг | Текст не вылезает, кнопки тапабельны |
| Категории бейджей | Сетка адаптируется (1 колонка на мобиле?) |
| Детейл бейджа | Не обрезается горизонтально |
| Профиль-кабинет | Вкладки переключаются, нет горизонтального скролла |
| Inbox (counselor) | Кнопки Approve/Reject доступны на мобиле |
| Модальные окна | Не выезжают за экран |

**Скрины:** min 3 скрина в мобильном вью (375px)

---

### Блок 4 — Чат с Валюшей

Залогинься как participant, открой чат.

| Тест | Запрос | Ожидание |
|------|--------|----------|
| C1 | "Привет, как меня зовут?" | Знает nickname из JWT (после M5-R3-C) |
| C2 | "В каком я отряде?" | Знает squad_name |
| C3 | "Какая сейчас смена?" | Знает shift_name |
| C4 | "Сколько у меня незакрытых заявок?" | Знает pending badge count |
| C5 | Пустое сообщение `""` | Не крашится, корректный ответ или подсказка |
| C6 | Сообщение 2001 символ | Получает ошибку "слишком длинное сообщение" (лимит 2000 после M5-R4-C) |
| C7 | "Расскажи про бейджи" | Содержательный ответ |

**Скрин:** каждый тест с ответом Валюши (можно один большой скрин с историей диалога)
