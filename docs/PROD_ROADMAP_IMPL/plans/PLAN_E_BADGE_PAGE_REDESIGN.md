## Текущее состояние (диагноз)

### Что есть сейчас

Страница значка (`BadgeView`) содержит:
1. Заголовок + название категории
2. Иконка значка (160px circle)
3. Панель скинов (СОЗДАТЬ С ПОМОЩЬЮ ИИ / КЛАССИКА / МОЙ АРТ / ПРЕДЛОЖИТЬ СВОЙ АРТ)
4. Прогресс-секции (ИИ-АРТЫ / ОДОБРЕННЫЕ / В КОЛЛЕКЦИИ) — аккордеоны
5. Кнопка "В МОЙ ПУТЬ"
6. **Гигантское hero-изображение** (max-height: 480px, object-fit: contain)
7. Текстовые блоки (description, nameExplanation, skillTips, importance, etc.)
8. Dock уровней (level-bubble) — внизу страницы

### Ключевые проблемы

#### P1. Hero-изображение занимает 50-60% viewport
- `badge-hero-media__image` имеет `max-height: 480px` — на десктопе это огромный блок
- Фото значка визуально важно, но не должно быть основным контентом
- На мобильном лучше, но на десктопе выглядит несоразмерно

#### P2. Контент ниже hero — невидим без долгого скролла
- Описание, критерии, "как прокачать" — всё спрятано под огромным фото
- Level-dock с иконками уровней — в самом низу, пользователь может не долистать

#### P3. Дублирование заголовков в текстовых секциях
**Причина:** `BadgeView.tsx:779` и `BadgeLevelView.tsx:1040` добавляют хардкодированный `<h4>Как прокачать навык</h4>`, а сам `skillTips` из JSON уже может начинаться с "Как прокачать навык?". Аналогично для `howToBecome` и `criteria`.

Файлы → строки:
- `BadgeView.tsx:779` — `<h4>Как прокачать навык</h4>` + `skillTips` (может дублировать)
- `BadgeView.tsx:766` — `<h4>Описание</h4>` + `description` (может дублировать)
- `BadgeLevelView.tsx:1040` — аналогично

#### P4. CSS-хардкоды, негибкая сетка
- `badge-hero-icon`: `width: 160px; height: 160px` — не масштабируется
- `level-bubble`: `width: 180px` — фиксированная ширина
- `level-bubble-icon`: `width: 160px; height: 160px` — фиксированная
- `badge-content-grid`: `grid-template-columns: 1.2fr 0.8fr` — колонки схлопываются только при 1024px, слишком поздно
- `content-block`: `padding: 2rem` — много паддинга, на мобильном переполняется

#### P5. Z-index конфликты
- `.route-confirm-overlay`: `z-index: 12000`
- Share modal: `z-index: 12000` (inline style)
- Confetti: `z-index: 9999`
- Могут перекрываться при одновременном показе

#### P6. Навигация между уровнями
- Level-dock внизу страницы — пользователь может не знать что туда надо скроллить
- При навигации назад (BadgeLevelView → BadgeView) scroll restoration может не срабатывать корректно
- Matching уровней по строке `level` (e.g. "Базовый уровень") — может не совпасть при изменении текста

#### P7. Аккордеоны прогресса (ИИ-АРТЫ/ОДОБРЕННЫЕ/В КОЛЛЕКЦИИ)
- Занимают видное место, но показывают "Пока пусто" для новых пользователей
- Пустое состояние не информативно — нет подсказки что делать дальше
