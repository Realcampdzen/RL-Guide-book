### D1: Prompt sanitization (`_sanitize_user_prompt`)

```
IMAGES_USER_PROMPT_MAX_LEN = env('IMAGES_USER_PROMPT_MAX_LEN', default=300)

Pipeline: HTML strip → injection check → truncate
- HTML strip: re.compile(r'<[^>]+>').sub('', text)
- Injection keywords: 'ignore previous', 'forget instructions', 'jailbreak', 'disregard', 'override prompt'
  → при совпадении: возврат '' + лог [IMAGES_SAFETY] prompt_injection_attempt device=<hash8>
- Truncation при len > 300: лог [IMAGES_SANITIZE] prompt truncated device=<hash8> len=<original>
```

**`_hash_key(k)`** — SHA-256[:8] hex, не reversible, safe to log.

**Backward compat:** все существующие вызовы без user_prompt не затронуты (parameter optional).

### D2: Per-camp daily quota (`_check_images_camp_daily_quota`)

```
IMAGES_CAMP_DAILY_LIMIT = env('IMAGES_CAMP_DAILY_LIMIT', default=200)

Storage: _images_camp_daily dict (in-memory, thread-safe via Lock)
Key: campId из JWT payload → если пусто, fallback на deviceId
Reset: автоматически при смене UTC-даты (сравнение строки YYYY-MM-DD)
При превышении: 429 + {"error": "Лимит генерации изображений для смены исчерпан", "retryAfter": "tomorrow"}
Лог: [IMAGES_QUOTA] daily_limit_hit campId=<hash8> ts=<UTC ISO>
```

**Порядок проверок в images_generate():**
1. JWT auth
2. Per-device rate limit (10/мин) — без изменений
3. Per-camp daily quota (новый) — **до** парсинга body
4. Парсинг body + `_sanitize_user_prompt` — **до** передачи в OpenAI
