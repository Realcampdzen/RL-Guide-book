# Инструкция по добавлению изображений для значков

## 📁 Структура файлов

Все изображения значков хранятся в папке `public/Новые значки/` по следующей структуре:

```
public/
└── Новые значки/
    └── [Название категории]/
        └── [Название значка]/
            ├── 1 [название базового уровня].jpg
            ├── 2 [название продвинутого уровня].jpg  (если есть)
            └── 3 [название экспертного уровня].jpg  (если есть)
```

### Пример: Значок "Беспорядок Дня" (ID: 1.2)

```
public/
└── Новые значки/
    └── За личные достижения/
        └── Беспорядок дня/
            ├── 1 беспорядок дня.jpg
            ├── 2 генератор фишек.jpg
            └── 3 хранитель беспорядка.jpg
```

## 📝 Правила именования файлов

### 1. Название папки категории
- Используется точное название категории из данных
- Пример: `За личные достижения`
- Маппинг категорий находится в `src/utils/badgeImages.ts` в объекте `categoryFolderMap`

### 2. Название папки значка
- Используется название значка в **lowercase** (строчными буквами)
- **Исключение**: Для значка "Беспорядок Дня" папка называется `Беспорядок дня` (с большой "Б" и маленькой "дня")
- Специальные символы удаляются, остаются только буквы, цифры, пробелы и дефисы

### 3. Название файла изображения
Формат: `[Номер уровня] [название уровня в lowercase].jpg`

- **Номер уровня**: 
  - `1` - базовый уровень
  - `2` - продвинутый уровень
  - `3` - экспертный уровень
- **Название уровня**: берется из поля `title` уровня в JSON файле, приводится к lowercase
- **Расширение**: обязательно `.jpg`

### Примеры имен файлов:
- Базовый уровень: `1 беспорядок дня.jpg`
- Продвинутый уровень: `2 генератор фишек.jpg`
- Экспертный уровень: `3 хранитель беспорядка.jpg`

## 🎨 Размеры изображений на разных экранах

### Экран категории (список значков)
- **Контейнер**: 80px × 80px (круглый)
- **Размер изображения**: 72px × 72px
- **Размер в коде**: `size="medium"`
- **Отступ**: 4px с каждой стороны

### Экран значка (шапка)
- **Контейнер**: 80px × 80px (круглый)
- **Размер изображения**: 80px × 80px
- **Размер в коде**: `size="large"`
- **Отступ**: минимальный

### Экран значка (пузыри внизу справа)
- **Контейнер**: 160px × 160px (круглый)
- **Размер изображения**: 158px × 158px
- **Размер в коде**: `size="xlarge"`
- **Отступ**: 1px с каждой стороны (почти полностью заполняет контейнер)

### Экран уровня значка (шапка)
- **Контейнер**: 80px × 80px (круглый)
- **Размер изображения**: 80px × 80px
- **Размер в коде**: `size="large"`
- **Отступ**: минимальный

### Экран уровня значка (пузыри внизу справа)
- **Контейнер**: 160px × 160px (круглый)
- **Размер изображения**: 158px × 158px
- **Размер в коде**: `size="xlarge"`
- **Отступ**: 1px с каждой стороны

## 🔧 Добавление нового значка

### Шаг 1: Подготовка изображений
1. Создайте изображения для каждого уровня значка
2. Рекомендуемый размер исходного изображения: **не менее 200×200px** (для качества)
3. Формат: **JPG**
4. Изображение должно быть квадратным (1:1)

### Шаг 2: Определение структуры
1. Найдите JSON файл значка в `ai-data/category-[id]/[badge-id].json`
2. Проверьте:
   - `categoryId` - для определения папки категории
   - `title` - название значка (для папки)
   - `levels[]` - массив уровней с `id`, `title` для каждого уровня

### Шаг 3: Создание папок и файлов
1. Создайте папку категории (если не существует):
   ```
   public/Новые значки/[Название категории]/
   ```

2. Создайте папку значка:
   ```
   public/Новые значки/[Название категории]/[название значка в lowercase]/
   ```

3. Добавьте файлы изображений:
   - Для базового уровня: `1 [название базового уровня в lowercase].jpg`
   - Для продвинутого уровня: `2 [название продвинутого уровня в lowercase].jpg`
   - Для экспертного уровня: `3 [название экспертного уровня в lowercase].jpg`

### Шаг 4: Добавление маппинга категории (если новая категория)
Если категория еще не добавлена в маппинг, откройте `src/utils/badgeImages.ts` и добавьте запись:

```typescript
const categoryFolderMap: Record<string, string> = {
  '1': 'За личные достижения',
  '2': 'Название новой категории', // Добавьте здесь
  // ...
};
```

## 🐛 Отладка

### Если изображение не отображается:

1. **Проверьте консоль браузера** (F12):
   - Должны быть логи `getBadgeImagePath: входные параметры`
   - Проверьте сформированный путь к изображению

2. **Проверьте структуру файлов**:
   - Правильное название папки категории
   - Правильное название папки значка (lowercase)
   - Правильное имя файла (номер + название уровня в lowercase)

3. **Проверьте маппинг категории**:
   - Категория должна быть в `categoryFolderMap` в `src/utils/badgeImages.ts`

4. **Проверьте код**:
   - Проверки для нового значка должны быть добавлены во всех местах в `src/App.tsx`

5. **Проверьте Vite плагин**:
   - Убедитесь, что dev-сервер перезапущен после изменений в `vite.config.ts`

## ⚠️ Важные замечания

1. **Регистр букв важен**: 
   - Папка значка должна быть в lowercase (кроме специальных случаев)
   - Имена файлов должны быть в lowercase

2. **Пробелы в именах**: 
   - Пробелы в именах папок и файлов допустимы
   - Система автоматически кодирует их в URL

3. **Кириллица**: 
   - Полностью поддерживается в именах папок и файлов
   - Vite плагин автоматически обрабатывает кириллицу

4. **Формат изображений**: 
   - Только JPG
   - Рекомендуемый размер исходника: минимум 200×200px

5. **Одноуровневые значки**: 
   - Для одноуровневых значков используется только файл `1 [название].jpg`
   - Остальные уровни не нужны
