# SMM Playbook v1 — Реальный Лагерь

## Цель
Сделать комментарии НейроСтёпы под постами не формальностью, а усилителем:
1) удержания,
2) обсуждения,
3) конверсии в диалог/заявку на смену.

## Контекст
- Канал: @realcampspb
- Публикации уже запланированы (контент-план фиксирован).
- Значит, оптимизация идёт через комментарии, ответы и CTA-слой.

## Принципы
- Комментарий = второй смысловой слой поста.
- Без спама, без выдуманных фактов.
- 1 комментарий на пост.
- Короткие абзацы с пустой строкой.

## Базовая структура комментария
1. Смысл поста (1 абзац)
2. Польза для детей/родителей (1 абзац)
3. Инсайт/факт (1 абзац)
4. Мягкий CTA + фирменная ИИ-фраза (1 абзац)

## KPI
- % постов с ответами в треде
- среднее число реплаев на комментарий
- число входящих диалогов после CTA
- число заявок на весеннюю смену из SMM-касания
