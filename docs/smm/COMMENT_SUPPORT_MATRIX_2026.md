# COMMENT_SUPPORT_MATRIX_2026.md

Матрица: тип поста -> лучший тип комментария -> CTA.

| Тип поста | Лучший угол комментария | Обязательный пример | CTA |
|---|---|---|---|
| Событие смены | Что прокачивается реально | Сцена из дня/активности | «Разберу, как это влияет на ребёнка после смены» |
| Пост про ИИ | ИИ как тренажёр мышления | Запрос -> проверка -> корректировка | «Покажем это на мастер-классе на смене» |
| Творчество/медиа | Авторство + обратная связь | Черновик -> доработка -> результат | «Покажу, какие значки здесь закрываются» |
| Командные дела | Коллаборация и ответственность | Роль в команде -> итог | «Подберём трек под темперамент ребёнка» |
| FAQ/оргпост | Ясность и спокойствие | Чёткий ответ с пунктами | «Финальные детали подтвердят организаторы» |
| Прогрев/анонс смены | Fit, а не давление | Кому особенно подойдёт | «Можно в личке быстро прикинуть ваш сценарий» |

## Быстрый фильтр качества

Перед отправкой комментария проверь:
- есть ли конкретный пример;
- есть ли польза для родителя;
- есть ли 1 инсайт;
- есть ли мягкий CTA;
- нет ли пустой конструкции «не только/а ещё» без факта.
