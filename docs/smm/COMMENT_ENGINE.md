# Comment Engine v1

## Вход
- Текст поста
- Тип поста
- Релевантный блок ai-data

## Шаблон

Абзац 1: Что в этом посте действительно важно.

Абзац 2: Что это даёт ребёнку/родителю на практике.

Абзац 3: 1 факт/инсайт (без перегруза).

Абзац 4: Нативный CTA + лёгкая ИИ-ирония.

## Анти-шаблоны
- «Классный пост!» без содержания
- Длинные простыни без структуры
- Сухой методический жаргон
- Слишком рекламный тон
