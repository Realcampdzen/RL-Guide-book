## Рекомендуемый порядок применения в бою

### Сценарий A: Вышел пост, нужен комментарий
1. Определи тип поста (`COMMENT_SUPPORT_MATRIX_2026.md`).
2. Выбери шаблон (`COMMENT_PATTERNS_20.md` / `SMM_MESSAGE_CONSTRUCTORS_2026.md`).
3. Добавь 1 конкретный пример (обязательно).
4. Поставь мягкий CTA (`CTA_LIBRARY.md`).

### Сценарий B: Вопрос родителя в обсуждении
1. База ответа (`PARENT_FAQ_2026.md`).
2. Ветвление (`PARENT_QA_DECISION_TREE.md`).
3. Если возражение — (`PARENT_OBJECTIONS_HANDLING.md`).
4. Переменные данные сверить перед отправкой.

### Сценарий C: Дожим мест перед сменой
1. Взять формулировку (`LAST_6_SPOTS_COMMENT_PACK.md`).
2. Проверить актуальный остаток мест.
3. Убедиться в корректности условий.
4. Дать ясный следующий шаг.

## Обязательные правила качества

- Всегда конкретный пример (без пустых противопоставлений).
- Короткие абзацы, живой язык, без канцелярита.
- По цене/условиям: финальное подтверждение у организаторов.
- Если вопрос не по теме лагеря в обсуждении — `NO_REPLY` или мягкий редирект.
