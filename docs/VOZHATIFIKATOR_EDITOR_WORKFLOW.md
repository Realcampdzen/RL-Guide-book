# Воркфлоу редактора: вычитка и правки «Вожатификатор»

## О чём этот документ

Пошаговая инструкция для редактора по вычитке и правкам книги «Вожатификатор» перед публикацией в разделе личного кабинета. Выполняйте шаги по порядку и отмечайте чекбоксы по мере выполнения.

- **Рабочий документ для редактуры (подготовленный текст):** [docs/вожатификатор.md](docs/вожатификатор.md). Правки вносятся в этот файл. Этот же файл является источником текста книги на сайте: в личном кабинете книга показывается из Markdown (в режиме разработки — напрямую из `docs/`, при сборке — копия попадает в сборку автоматически).
- **Исходный файл (альтернатива):** [public/VZhTFKTR.docx](public/VZhTFKTR.docx) — оригинал в Word, если правки ведут в Word; ссылка «DOCX» в разделе Вожатификатор ведёт на скачивание этой версии.
- **Итог:** финальный текст в [docs/вожатификатор.md](docs/вожатификатор.md) с расставленными заголовками `#` и `##`. Оглавление на сайте строится автоматически по этим заголовкам. Экспорт в PDF для раздачи — по желанию, отдельно.

При работе по пути «текст в MD» этапы 1.1 и 1.2 выполняются в [docs/вожатификатор.md](docs/вожатификатор.md); этап 1.3 (структура) — расстановка заголовков `#` и `##` в том же файле. Отдельно выкладывать PDF или править оглавление вручную для сайта **не нужно** — сайт показывает текст из MD и строит оглавление по заголовкам.

**Рекомендуемый порядок:** сначала этап 1.1 (чёрный список), затем 1.2 (вычитка), затем 1.3 (структура). После правок достаточно сохранить [docs/вожатификатор.md](docs/вожатификатор.md); при следующей сборке или в режиме разработки пользователи увидят обновлённый текст книги.

## Этап 1.1 — Чёрный список «Юный Строитель»

**Цель:** убрать или нейтрально заменить все упоминания лагеря «Юный Строитель» в документе.

### Инструмент Word

- Откройте документ, нажмите **Ctrl+H** (Найти и заменить).
- Выполняйте поиск по одному варианту из таблицы ниже, подбирайте замену по смыслу предложения.

### Варианты для поиска (по одному)

| Искать | Заменить на (по контексту) |
|--------|----------------------------|
| Юный Строитель | лагерь, наш лагерь, база, место смены |
| Юного Строителя | лагеря, нашей базы, места смены |
| Юному Строителю | лагерю, базе, месту смены |
| Юным Строителем | лагерем, базой |
| Юном Строителе | лагере, базе, на смене |
| юный строитель | лагерь, наш лагерь (при необходимости то же в нижнем регистре) |

### Проверка после замен

- В Word снова откройте **Найти** (Ctrl+F) и по очереди поищите: **Юный**, **Строитель** (отдельно).

Ведите вычитку **по главам/разделам сверху вниз** (от начала документа к концу), чтобы не пропустить блоки.

При чтении каждого фрагмента проверяйте:

- **Орфография и пунктуация** — исправьте ошибки.

## Этап 1.3 — Структура для сайта

**Цель:** сделать явные заголовки для оглавления на сайте — по ним строится навигация по главам в личном кабинете (клик по пункту прокручивает к разделу).

### Действия в Markdown ([docs/вожатификатор.md](docs/вожатификатор.md))

1. **Главы:** в начале каждой главы добавьте строку с одним решёткой и текстом: `# НАЗВАНИЕ ГЛАВЫ`.
2. **Крупные разделы внутри глав:** добавьте заголовки с двумя решётками: `## Название раздела`.
3. Убедитесь, что нет «голого» текста, который по смыслу является заголовком, но без `#` или `##`.
4. Проверьте иерархию: после `#` идут `##` того же раздела.

### Если правите в Word

1. **Главы:** примените стиль **«Заголовок 1»** к заголовкам глав.
2. **Разделы:** примените **«Заголовок 2»** к заголовкам крупных разделов.
3. При экспорте или копировании в MD убедитесь, что заголовки превращаются в `#` и `##`.

### Проверка структуры

- В [docs/вожатификатор.md](docs/вожатификатор.md) найдите все строки, начинающиеся с `#` или `##` — это и будет оглавление на сайте.
- Убедитесь, что список глав и разделов выглядит логично и ничего не пропущено.

- [ ] **Все главы и крупные разделы отмечены заголовками `#` и `##` в [docs/вожатификатор.md](docs/вожатификатор.md).**

## Финальные шаги

### Сохранение

- Сохраните [docs/вожатификатор.md](docs/вожатификатор.md) (и при необходимости .docx, если правили в Word и синхронизировали с MD).
- При необходимости сделайте бэкап или зафиксируйте версию (например, копия файла с датой в имени).

### Публикация на сайте

- Текст книги на сайте берётся из [docs/вожатификатор.md](docs/вожатификатор.md). В режиме разработки (npm run dev) файл отдаётся напрямую из `docs/`; при сборке (npm run build) он копируется в сборку автоматически. Отдельно класть файл в `public/` не требуется.
- Оглавление в разделе «Вожатификатор» строится автоматически по заголовкам `#` и `##` в MD — ничего править вручную не нужно.

### Экспорт в PDF (по желанию)

- Если нужен PDF для раздачи (вне сайта): экспортируйте из Word или сконвертируйте MD → PDF по своей инструкции. Для просмотра книги в личном кабинете PDF не используется.
