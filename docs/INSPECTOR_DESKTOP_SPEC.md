# Инспектор Пользы на десктопе — расположение и вид

Описание того, **где** на десктопе находится блок «Инспектор Пользы» и **как он должен выглядеть** (актуальное состояние).

---

## 1. Где находится

- **Экран:** личный кабинет в режиме «кабина» (`profile-spaceship-root`), главный экран (hub), когда открыт раздел «Главный экран», а не панель Инспектора/Паспорта и т.д.
- **Условие показа:** только при `panelActiveView === null` и `seeOtradBlocksInView === true` (в кабине по сути всегда true). Если пользователь открыл, например, Инспектор или Паспорт, полоска вверху не рендерится.
- **Viewport:** десктоп, ширина окна **≥ 1181px**. Ниже этого порога блок скрыт классом `profile-view-cabin-top-inspector-page--desktop-only` (по умолчанию `display: none`).
- **Позиция на экране:** **вверху по центру**, над центральной панелью кабины. Фиксированный слой (`position: fixed`), не скроллится.

---

## 2. Позиционирование (числа)

- **Позиция:**
  - `left: var(--desktop-layer-left)` — отступ слева (обычно `clamp(376px, 23.4vw, 438px)`).
  - `right: var(--desktop-layer-right)` — отступ справа (обычно `clamp(168px, 10.2vw, 196px)`).
  - `top: clamp(10px, 1.6vh, 18px)` — отступ сверху от края окна.
- **Z-index:** `10145` — выше центральной панели (10080) и левой колонки (10140), чтобы блок не перекрывался.
- **Ширина зоны:** между `--desktop-layer-left` и `--desktop-layer-right`. Внутри по центру располагается сама карточка (кнопка) с `max-width: min(660px, 96%)`, `margin-inline: auto`.

---

## 3. Размеры

**Внешний контейнер** (`.profile-view-cabin-top-inspector-page--desktop-only`):

- Высота: `min-height: 60px`, `max-height: 70px`.
- Отступы: `padding: 6px 18px 8px`.
- `overflow: hidden`.

**Карточка-кнопка** (`.profile-view-cabin-top-inspector`):

- Высота: `min-height: 54px`, `max-height: 58px`.
- Отступы: `padding: 7px 14px 8px`, `gap: 5px` (между заголовком, подзаголовком и прогрессом).
- Ширина: `max-width: min(660px, 96%)`, по центру горизонтально.

Нижняя граница блока должна оставаться **выше** начала центральной панели (`--desktop-layer-top` ≈ 86px), чтобы не наезжать на контент центра.

---

## 4. Как выглядит

- **Фон карточки:** наследуется от базового `.profile-view-cabin-top-inspector` — градиенты (cyan/magenta) и полупрозрачный тёмный фон (см. `profile-view-spaceship.css`).
- **Обводка/тень:** только лёгкая обводка без «ореола»:  
  `box-shadow: 0 0 0 1px rgba(var(--cabin-neon-cyan-rgb), 0.2)`.
- **Скругления:** у кнопки `border-radius: 16px`, нижние углы усилены: `border-bottom-left-radius: 20px`, `border-bottom-right-radius: 20px`.
- **Контент:**
  - Заголовок: «Инспектор Пользы», `font-size: clamp(13px, 0.95vw, 15px)`, `line-height: 1.2`, `flex-shrink: 0`.
  - Подзаголовок: «Игровая система полезных дел...», `font-size: 11px`, в одну строку с `text-overflow: ellipsis` при переполнении.
  - Полоска прогресса: высота `5px`, без псевдоэлементов.
- **Псевдоэлементы и оверлеи:** у десктопного варианта **отключены** (не должны быть видны):
  - У контейнера и кнопки все `::before` и `::after` скрыты (`display: none`, `content: none`, `visibility: hidden`) для класса `profile-view-cabin-top-inspector-page--desktop-only`, в том числе у полоски прогресса.
- **Вертикальное выравнивание:** у кнопки `display: flex`, `flex-direction: column`, `justify-content: center`, чтобы заголовок, подзаголовок и прогресс не сплющивались и были по центру по вертикали.

---

## 5. Поведение

- **Клик:** по карточке открывается панель «Инспектор Пользы» (то же, что при клике по пункту «Инспектор» в правой колонке кабины). На десктопе пункт «Инспектор» в правой колонке скрыт (`display: none`), вход в раздел — только через эту верхнюю полоску.
- **Контейнер:** `pointer-events: none`, у кнопки — `pointer-events: auto`, чтобы клики шли только по карточке.

---

## 6. Где править

- **Стили (десктоп, вид и расположение):**  
  `src/styles/profile-view-spaceship.css` — блок `@media (min-width: 1181px)`, селекторы `.profile-view-cabin-top-inspector-page--desktop-only` и вложенные (примерно строки 2068–2150). Базовые стили карточки (фон, градиенты) — `.profile-view-cabin-top-inspector` в том же файле.
- **Разметка и условия показа:**  
  `src/views/ProfileView.tsx` — фрагмент с `profileOuterContent`, условие `panelActiveView === null && seeOtradBlocksInView`, блок с классами `profile-view-cabin-top-inspector-page profile-view-cabin-top-inspector-page--desktop-only` (около 2566–2585).

---

## 7. Краткий чеклист «как должно быть»

- [ ] Виден только при ширине окна ≥ 1181px.
- [ ] Показывается только на главном экране кабины (hub), когда не открыта другая панель.
- [ ] Расположен вверху по центру, между отступами `--desktop-layer-left` и `--desktop-layer-right`, отступ сверху `clamp(10px, 1.6vh, 18px)`.
- [ ] Высота контейнера 60–70px, карточки 54–58px; нижний край выше центральной панели.
- [ ] Один ряд: заголовок, подзаголовок, полоска прогресса; без видимых псевдоэлементов/оверлеев; лёгкая обводка, скруглённые нижние углы.
- [ ] Клик по карточке открывает раздел «Инспектор Пользы»; в правой колонке на десктопе пункт «Инспектор» скрыт.

Если при изменении стилей или вёрстки что-то из этого перестанет выполняться — стоит свериться с этой спекой и с текущим кодом в указанных местах.
