# Инструкция: изображения на страницах значков и уровней

Эта инструкция описывает, как добавлять изображения на страницы значка и его подуровней (экран значка и экран уровня), чтобы они отображались в карточке под названием значка.

## Что должно быть на экране

- Экран значка: под иконкой и названием значка появляется крупная карточка‑изображение.
- Экран уровня: под иконкой и названием уровня появляется карточка‑изображение соответствующего уровня.
- Общая информация и критерии остаются ниже, в стандартных блоках.

## Откуда берутся изображения

Изображения берутся из папки `public/Новые значки/` и подгружаются через `getBadgeImagePath` из `src/utils/badgeImages.ts`.

Структура для изображений реализма:

```
public/
└── Новые значки/
    └── [Название категории]/
        └── [Название значка]/
            └── реализм/
                ├── 1 [название базового уровня].jpg
                ├── 2 [название продвинутого уровня].jpg
                └── 3 [название экспертного уровня].jpg
```

Для одноуровневых значков используется только файл `1 ...jpg`.

Пример (Валюша):

```
public/Новые значки/За личные достижения/Валюша/реализм/
├── 1 Валюша.jpg
├── 2 Помнящий Факты.jpg
└── 3 Настоящий Валюша.jpg
```

## Как устроены страницы

- Экран значка: `src/views/BadgeView.tsx`
  - Получает изображение через `getBadgeImagePath(..., 'realism')`.
  - Рендерит секцию `.badge-hero-media` под заголовком.
  - Для изображения берется базовый уровень (если значок многоуровневый).

- Экран уровня: `src/views/BadgeLevelView.tsx`
  - Получает изображение через `getBadgeImagePath(..., 'realism')`.
  - Для уровня передаются `levelId` и `levelTitle`, чтобы выбрать файл `2 ...` или `3 ...`.
  - Рендерит ту же секцию `.badge-hero-media`.

Стили карточки заданы в `src/styles/badge-view.css`:

```
.badge-hero-media
.badge-hero-media__frame
.badge-hero-media__image
```

Если нужно изменить размеры, рамку или цвет — правьте эти классы.

## Как добавить изображения для другой категории

1. Найдите данные значка в `ai-data/category-[id]/[badge-id].json`.
   - Проверьте `categoryId`, `title`, `levels[].title`.
2. Убедитесь, что категория есть в `categoryFolderMap`:
   - Файл: `src/utils/badgeImages.ts`
   - Пример: `'1': 'За личные достижения'`
3. Проверьте имя папки значка:
   - Функция: `getBadgeFolderName` в `src/utils/badgeImages.ts`
   - Если папка не совпадает с нормализацией (например, особые символы или регистр), добавьте явный маппинг по `badgeId`.
4. Добавьте изображения в `public/Новые значки/[Категория]/[Значок]/реализм/`:
   - `1 [название базового уровня].jpg`
   - `2 [название продвинутого уровня].jpg` (если есть)
   - `3 [название экспертного уровня].jpg` (если есть)
5. Проверьте отображение:
   - Откройте страницу значка (должен показываться файл `1 ...`).
   - Перейдите на уровни (должны показываться файлы `2 ...` и `3 ...`).

## Правила именования

- Названия файлов должны соответствовать названиям уровней из JSON.
- Номер уровня в имени файла:
  - `1` — базовый
  - `2` — продвинутый
  - `3` — экспертный
- Регистр и пробелы сохраняются в URL (используется `encodeURIComponent`), но на хостингах с чувствительностью к регистру нужно строго совпадение.

## Частые проблемы

- **Изображение не показывается**:
  - Проверьте `categoryFolderMap` и `getBadgeFolderName`.
  - Проверьте точное совпадение имени файла с названием уровня.
  - Убедитесь, что файл лежит именно в `реализм/`.
- **Открывается только базовый уровень**:
  - Проверьте, что файл `2 ...` и `3 ...` существуют и соответствуют `levels[].title`.
- **Неверный путь**:
  - Проверьте регистр букв и пробелы в именах папок/файлов.

## Ключевые файлы для ориентирования

- `src/utils/badgeImages.ts` — построение путей к изображениям
- `src/views/BadgeView.tsx` — экран значка
- `src/views/BadgeLevelView.tsx` — экран уровня
- `src/styles/badge-view.css` — стили карточки с изображением
