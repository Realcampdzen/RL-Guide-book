# 🔧 Диагностика ошибки "connectionfailure"

## Быстрая диагностика

### 1. Проверьте, запущен ли сервер

```bash
# Запустите сервер
npm run dev:html
# или
node server-html.js
```

Вы должны увидеть сообщение:
```
✅ HTML сервер успешно запущен!
📄 Порт: 4002
```

### 2. Проверьте доступность порта

**Windows:**
```bash
netstat -an | findstr ":4002"
```

**Linux/Mac:**
```bash
lsof -i :4002
# или
netstat -an | grep 4002
```

Если порт занят, вы увидите процесс. Завершите его или используйте другой порт.

### 3. Проверьте подключение

**Через браузер:**
- Откройте: http://localhost:4002/
- Должна загрузиться страница bluenest.html

**Через тестовый скрипт:**
```bash
npm run test:html
# или
node test-html-server.js
```

### 4. Типичные ошибки и решения

#### ❌ "ECONNREFUSED" или "connectionfailure"
**Причина:** Сервер не запущен или недоступен

**Решение:**
1. Убедитесь, что сервер запущен: `npm run dev:html`
2. Проверьте, что используете правильный порт (4002)
3. Проверьте файрвол/антивирус (может блокировать подключение)

#### ❌ "EADDRINUSE" - Порт уже занят
**Причина:** Другой процесс использует порт 4002

**Решение:**
```bash
# Windows - найти процесс
netstat -ano | findstr :4002
# Завершить процесс (замените PID на реальный)
taskkill /PID <PID> /F

# Или используйте другой порт
set PORT=4003
node server-html.js
```

#### ❌ "Файл не найден"
**Причина:** Отсутствуют HTML файлы

**Решение:**
- Убедитесь, что файлы `bluenest.html` и `categories.html` находятся в корне проекта
- Проверьте права доступа к файлам

#### ❌ Таймаут подключения
**Причина:** Сервер не отвечает или заблокирован файрволом

**Решение:**
1. Проверьте логи сервера на наличие ошибок
2. Временно отключите файрвол/антивирус для теста
3. Проверьте, что сервер слушает на `0.0.0.0`, а не только `127.0.0.1`

### 5. Расширенная диагностика

#### Проверка через curl (если установлен)
```bash
curl -v http://localhost:4002/
curl -v http://localhost:4002/bluenest.html
```

#### Проверка через PowerShell (Windows)
```powershell
Invoke-WebRequest -Uri http://localhost:4002/ -UseBasicParsing
```

#### Просмотр логов сервера
Сервер теперь логирует все запросы. Смотрите консоль для:
- Входящих запросов
- Ошибок чтения файлов
- Статусов ответов

### 6. Альтернативные порты

Если порт 4002 не работает, попробуйте:

```bash
# Порт 4003
PORT=4003 node server-html.js

# Порт 4004
PORT=4004 node server-html.js

# Или через npm
PORT=4003 npm run dev:html
```

### 7. Проверка файлов

Убедитесь, что файлы существуют:
```bash
# Windows
dir bluenest.html
dir categories.html

# Linux/Mac
ls -la bluenest.html categories.html
```

## Получение помощи

Если проблема не решена:

1. **Соберите информацию:**
   - Версия Node.js: `node --version`
   - Операционная система
   - Полный текст ошибки из консоли
   - Логи сервера

2. **Проверьте логи:**
   - Запустите сервер и посмотрите на вывод в консоли
   - Все запросы и ошибки теперь логируются

3. **Проверьте сетевые настройки:**
   - Файрвол Windows
   - Антивирус
   - VPN (может блокировать localhost)
