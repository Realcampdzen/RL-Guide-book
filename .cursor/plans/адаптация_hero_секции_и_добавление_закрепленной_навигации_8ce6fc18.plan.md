# Адаптация Hero секции и добавление закрепленной навигации

## Цель

Адаптировать hero секцию под стиль референса bluenest.html: убрать кнопку из hero, перенести подзаголовок ниже marquee, добавить закрепленную навигационную панель с кнопкой бота.

## Изменения в `bluenest.html`

### 1. Удаление кнопки "Начать путешествие" из Hero

- Удалить блок `.hero-cta-wrapper` с кнопкой из hero секции (строки 427-429)
- Удалить стили `.hero-cta-wrapper` (строка 223)

### 2. Перенос подзаголовка ниже Marquee

- Удалить `.hero-subtitle` из hero секции (строки 424-426)
- Создать новую секцию после marquee для размещения подзаголовка
- Добавить стили для новой секции с подзаголовком

### 3. Добавление закрепленной навигационной панели

- Создать новую секцию `.sticky-nav` с `position: fixed` в правом верхнем углу
- Добавить пункты меню: "Категории", "О лагере", "НейроВалюша" (кнопка бота)
- Стилизовать в стиле референса: светлый текст на темном фоне, hover эффекты
- Добавить JavaScript для открытия чат-бота при клике на "НейроВалюша"

### 4. Интеграция чат-бота

- Добавить скрипт для инициализации чат-бота (если нужно)
- Связать кнопку "НейроВалюша" с функционалом открытия чата

## Файлы для изменения

- `bluenest.html` - основной файл с изменениями структуры и стилей

## Детали реализации

### Структура sticky-nav:

```html
<div class="sticky-nav">
  <a href="http://localhost:3001" class="nav-link">Категории</a>
  <a href="https://realcampspb.ru" class="nav-link" target="_blank">О лагере</a>
  <button class="nav-link nav-bot-btn" id="neuro-valyusha-btn">НейроВалюша</button>
</div>
```



### Стили для sticky-nav:

- `position: fixed`
- `top: 2rem`
- `right: 4rem`
- `z-index: 101` (выше навигации)
- Вертикальное расположение элементов
- Стили в духе референса: светлый текст, hover эффекты
