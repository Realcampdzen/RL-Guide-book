## Example prompts

### 1) UI kit / tokens

“Используй skill `prisma-frontend-design`. Предложи дизайн-токены (цвета/типографика/радиусы/тени) для premium antique сайта. Сгенерируй `globals.css` variables и mapping для Tailwind.”

### 2) Homepage hero section

“Собери Hero секцию для главной. Стиль antique luxury editorial. Next.js App Router + Tailwind. Добавь 2 CTA, пример русского копирайта, и подготовь место под `next/image`.”

### 3) Featured collection grid

“Сделай секцию ‘Коллекции’ с 6 карточками. Карточки кликабельные, с хорошим фокусом, адаптивная сетка, без magic values, только tokens.”

### 4) Product card component

“Сделай `ProductCard` компонент. Варианты: compact и featured. Обязательны доступность и image sizes.”

### 5) Process section

“Секция ‘Процесс’ на 4 шага: эскиз → резьба → сборка → финиш. Минималистичные иконки, очень спокойная анимация (с учётом reduced motion).”
