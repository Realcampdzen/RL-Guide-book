## 2. Выполнено

### 2.1. Реализация плана «Шлифовка блока Смены и отряды»

**Файл:** [src/views/ProfileView.tsx](../src/views/ProfileView.tsx)

| Изменение | Детали |
|-----------|--------|
| **loadOrganizerData** | useCallback уже был; добавлен вызов `fireOn401()` первым при `res.status === 401` (убрана установка organizerError до fireOn401). |
| **401 в squad fetch (useEffect)** | Во втором useEffect при загрузке squads добавлена проверка `r.status === 401` и вызов `fireOn401()` перед return. |

| **Кнопки действий** | Обёртка `{accessToken && (...)}` — кнопки «Создать смену», «Обновить», «Выдать код» отображаются только при наличии токена. |
| **fireOn401 в POST** | Модалки создания смены, добавления отряда и выдачи кода уже вызывали fireOn401 при 401 — без изменений. |
