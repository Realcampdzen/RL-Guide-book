## 🎯 **ОБНОВЛЕНИЕ 2.0: ЧТО НОВОГО?**

Спустя более года разработки проект вырос из базового справочника в масштабную облачную платформу:
- **☁️ Supabase & Vercel:** Весь прогресс теперь синхронизируется через облако. Отказ от старых локальных JSON для пользователей.
- **🛡️ Гибкий Server-Side RBAC:** Авторизация на основе JWT токенов с разными правами видимости (Участник, Педагог, Вожатый, Родитель, Организатор и Developer). У каждого свой уникальный Личный Кабинет.
- **🎉 Share Center (AAA Прогресс-карточки):** Механика вирусного шеринга. Система собирает ваш 3D-аватар, значки, уровни и генерирует стильную социальную карточку (9:16 / 16:9) с ИИ-мотивацией.
- **🚀 Telegram & VK Интеграции:** Все заявки от отрядов пробрасываются в Telegram с помощью Webhooks, а статусы обновляются автоматически.

## ✨ **КЛЮЧЕВЫЕ КОМПОНЕНТЫ СИСТЕМЫ**

### 🤖 **НейроВалюша - AI-Помощник и Ко-Пилот**
- Общение с учетом контекста вашего кабинета и текущих целей.
- Генерация ИИ-артов и персональных гербов штаба Крыла или отряда.
- Автогенерация сценариев традиций для вожатых.

### 👔 **Smart Workspaces (Умные Кабинеты)**
Ежедневные дашборды для каждой роли в игре:
- **Реальный Отряд и Дневник** — для участников смены.
- **Совет Лагеря** — управление инициативами и голосованиями.
- **Кабинет Педагога / Вожатого** — панель проверки заявок на значки (Inbox).

### 🌐 **Spaceship UI (Веб-Приложение)**
- **React 19 + TypeScript 6 + Vite 8** архитектура.
- **Three.js** для 3D визуализации космического пространства и значков.
- Единый контейнер посадочной панели (Cockpit) для всех экранов меню.

## 🚀 **БЫСТРЫЙ СТАРТ И DEVELOPER SETUP**

### Предварительные требования
- **Node.js** 22+ (Vite 8 требует Node 20+)
- **Python** 3.8+

### 1. Установка
```bash
git clone https://github.com/Realcampdzen/RL-Guide-book.git
cd RL-Guide-book

# Frontend зависимости
npm install

# Backend зависимости
pip install -r requirements.txt
```

### 2. Настройка Окружения
Скопируйте конфиг и добавьте свои ключи `OPENAI_API_KEY`, а также (опционально) ссылки на вашу базу Supabase.
```bash
cp .env.example .env
```
*(См. подробности внутри `.env.example` — поддерживает как локальную разработку, так и облачную)*

### 3. Запуск Проекта (Local Dev)
Вы можете запустить проект целиком через скрипт (Windows):
```bash
start_all_services.bat
```
Либо вручную:
```bash
# Терминал 1: Frontend (React)
npm run dev

# Терминал 2: Backend (Flask)
python backend/app.py
```
> **Совет:** Для быстрой проверки работоспособности портов используйте команду `npm run self-check`. Если запущен бэкенд: `BACKEND_URL=http://localhost:4000 npm run self-check`.

## 🤝 **ВКЛАД В ПРОЕКТ (Git Flow)**

В проекте введен строгий гибридный Git-Flow (`CODE_REVIEW_PROTOCOL`):
1. **Мелкие фиксы UI (< 10 строк):** Пушатся напрямую в `main`.
2. **Архитектурные изменения:** Обязательная ветка `feature/<feature_name>` и PR-ревью другим (в том числе ИИ) агентом на отсутствие монолитного кода и хардкода API ключей.
