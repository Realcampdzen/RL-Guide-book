# Анализ зеленых цветов и оверлеев в bluenest.html

## Резюме
**Прямых зеленых цветов в коде НЕТ.** Зеленый цвет появляется визуально через эффект `mix-blend-mode: difference`, который инвертирует светлые цвета на темном фоне.

## Места появления зеленого цвета

### 1. Курсор - обводка (`.cursor-outline`)
**Строки:** 84-91
- **Цвет:** `rgba(244, 239, 228, 0.85)` (светлый кремовый)
- **Эффект:** `mix-blend-mode: difference`
- **Где видно:** Постоянно видимый круг вокруг курсора
- **Почему зеленый:** Светлый цвет через difference на темном фоне дает зеленоватый оттенок

### 2. Курсор - hover состояние (`.cursor-hover`)
**Строки:** 92-97
- **Цвет:** `var(--c-stark)` = `#f4efe4` (светлый кремовый)
- **Эффект:** `mix-blend-mode: difference`
- **Где видно:** При наведении на элементы с классом `.hover-target`
- **Почему зеленый:** Большой светлый круг через difference создает яркий зеленый эффект
- **Активируется на:**
  - Логотип (строка 524)
  - Ссылки в гормошке (строки 535-537)
  - Кнопка "Начать путешествие" (строка 611)
  - Ссылки в футере (строки 614-616)

### 3. Курсор - реактор (`.cursor-reactor`)
**Строки:** 98-107
- **Цвет:** Градиент с `var(--c-volt-glow)` и `var(--c-aurora)` (фиолетовые)
- **Эффект:** `mix-blend-mode: soft-light`
- **Где видно:** Большой размытый круг, следующий за курсором
- **Почему может быть зеленый:** soft-light может создавать неожиданные цветовые смешения

### 4. Верхняя навигация (`.nav`)
**Строки:** 156-164
- **Цвет:** `var(--c-stark)` = `#f4efe4` (светлый кремовый)
- **Эффект:** `mix-blend-mode: difference`
- **Где видно:** Верхняя навигационная панель
- **Почему зеленый:** Текст навигации через difference на темном фоне дает зеленоватый оттенок

### 5. Закрепленная навигация - гормошка (`.sticky-nav`)
**Строки:** 191-202
- **Цвет:** `var(--c-stark)` = `#f4efe4` (но сейчас переопределен на `#ff8c42` для ссылок)
- **Эффект:** `mix-blend-mode: difference`
- **Где видно:** Правая сторона экрана, подписи "Категории", "О лагере", "НейроВалюша"
- **Почему зеленый:** Контейнер `.sticky-nav` имеет difference, что может влиять на отображение
- **Примечание:** Сами ссылки имеют цвет `#ff8c42` (оранжевый), но контейнер с difference может создавать дополнительные эффекты

### 6. Оверлей на фоне героя (`.hero-bg`)
**Строки:** 272-286
- **Цвет:** Градиенты с фиолетовыми оттенками
- **Эффект:** `mix-blend-mode: screen`
- **Где видно:** Фоновый оверлей на hero секции
- **Почему может быть зеленый:** screen mode может создавать различные цветовые эффекты при смешении

## Цветовые переменные, участвующие в эффектах

- `--c-stark: #f4efe4` - светлый кремовый, основной источник зеленого через difference
- `--c-volt: #6a0dad` - темно-фиолетовый (используется в cursor-dot)
- `--c-volt-glow: rgba(139, 0, 255, 0.35)` - фиолетовый с прозрачностью
- `--c-aurora: rgba(139, 0, 255, 0.25)` - фиолетовый с прозрачностью

## Элементы с классом `.hover-target` (активируют зеленый курсор)

2. "Категории" в гормошке (строка 535)
3. "О лагере" в гормошке (строка 536)
4. "НейроВалюша" в гормошке (строка 537)
5. Кнопка "Начать путешествие" (строка 611)
6. "Категории" в футере (строка 614)
7. "О лагере" в футере (строка 615)
8. "ВКонтакте" в футере (строка 616)

## Выводы

**Основной источник зеленого цвета:**
- `mix-blend-mode: difference` на светлых элементах (`#f4efe4`)
- Наиболее заметен в `.cursor-hover` при наведении
- Также виден в `.cursor-outline` (постоянно)
- Влияет на навигацию через `.nav` и `.sticky-nav`

**Рекомендации:**
Если нужно убрать зеленый цвет, можно:
1. Убрать или изменить `mix-blend-mode: difference` на других режимах
2. Изменить цвет `--c-stark` на другой оттенок
3. Использовать другой режим смешивания для курсора
