# Project Brief: Путеводитель "Реальный Лагерь"

**Путеводитель** — это цифровая экосистема для системы значков "Реального Лагеря". Это не просто каталог наград, а интерактивный инструмент развития и соуправления.

## Core Mission
Трансформация "значка как награды" в "значок как инструмент развития навыков 4К" (Коллаборация, Критическое мышление, Креативность, Коммуникация).

## Key Components
1.  **Interactive 3D Web App:** Фронтенд на React 19 + Three.js для визуализации «созвездий» значков.
2.  **NeuroValyusha (НейроВалюша):** ИИ-ассистент (GPT-4o mini), помогающий в навигации по методике.
3.  **Knowledge Base:** 119 значков, 242 уровня, структурированные в JSON/Markdown.
4.  **Personal Cabinet (ЛК):** Полноценный кабинет с 15+ панелями: Движки, Совет, Инспектор, БРО, Мастерская, Дневник и др.

## Strategic Vision 2026
- **UGC (User Generated Content):** "Мастерская значков", где дети сами предлагают контент.
- **Viral AI Content:** Генерация карточек достижений и манифестов для соцсетей.
- **Hybrid Progress:** Сочетание LocalStorage для анонимности и облачного сохранения для участников смен.

## Target Audience
- **Travelers:** Анонимные пользователи (изучают систему).
- **Participants:** Дети в лагере (ведут маршруты, получают пруфы).
- **Parents:** Наблюдатели за прогрессом.
- **Creators:** Продвинутые участники, создающие новый контент.
