# Product Logic: Loops, Roles & Progression

Проект строится на трёх взаимосвязанных игровых циклах.

**Фокус:** развитие и творчество, 4К навыки (Коллаборация, Критическое мышление, Креативность, Коммуникация). Без соревновательных механик как приоритета (рейтинги, «Битва Движков», лента с лайками — переосмыслены). При разработке личного кабинета и механик ЛК — источник истины: [docs/STEPA_VISION_LC.md](../docs/STEPA_VISION_LC.md).

## 1. Core Loop (Маршрут развития)
`Категория -> Значок -> Уровень -> Реальное действие -> Пруф -> Конфетти/Прогресс`
- **Суть:** Геймификация методики. Каждое действие в реальности должно иметь отражение в цифровом профиле.
- **Технически:** Статусы уровней хранятся в `localStorage` по ID (например, `1.1.2`). При авторизации — синхронизация с Backend через JWT.

## 2. Social/Viral Loop (Поделись моментом)
`Действие -> Генерация карточки (ИИ) -> Репост в соцсети (9:16 / 16:9)`
- **Цель:** Виральность и привлечение новых участников через "Мастер-классы по ИИ".
- **Артефакты:** "Манифест намерения", "Герб команды", "Карточка достижений", "Карточка прогресса AAA".

## 3. Creator Loop (UGC / Мастерская)
`Опыт (1.16.1/2) -> Доступ к Мастерской -> Создание контента -> Модерация -> Канон`
- **Гейты:** Доступ открывается только после выполнения значков категории "Путеводитель" (1.16.1, 1.16.2).
- **Типы контента:** Новые значки, новые категории, кастомные арты (скины).

## 4. Team Loop (Движки)
`Создать Движок -> Пригласить участников -> Проекты (badge goals) -> Инициативы -> Совет`
- **Суть:** Коллаборативная механика. Команды (Движки) ведут проекты привязанные к значкам и голосуют за инициативы.
- **Интеграции:** Совет Лагеря (bridge инициатив), чат Движка, ИИ-генерация герба и флага.

## User Roles & Access (8 ролей)

| # | Роль | Ключ | Доступ |
|---|------|------|--------|
| 1 | Путешественник | `traveler` | LocalStorage, просмотр, без ИИ-чата. Дефолт |
| 2 | Участник | `participant` | JWT авторизация, ИИ-чат, Движки, синхронизация с backend |
| 3 | Родитель | `parent` | Наблюдатель прогресса ребёнка (по коду), свой ЛК. Рекомендации |
| 4 | Вожатый | `counselor` | Очередь подтверждений значков (inbox), панель отряда, отряд вожатых |
| 5 | Педагог | `educator` | Кабинет педагога (задания, расписание, группы), inbox значков |
| 6 | Старший вожатый | `shift_leader` | Создание смен/отрядов, выдача кодов, аналитика, отряд вожатых |
| 7 | Директор лагеря | `camp_director` | Организаторский уровень, полное управление |
| 8 | Разработчик | `developer` | Полный доступ, песочница, обход авторизации на localhost |

**Источник истины:** [src/types/authRole.ts](../src/types/authRole.ts)

## Progression System
- **Rank:** Растет от количества закрытых уровней. Rank Up оверлей при повышении.
- **Badges "In Path":** Текущие цели пользователя (маршруты).
- **Collection:** Завершенные маршруты.
- **4К Профиль:** Радар навыков (Коллаборация, Критическое мышление, Креативность, Коммуникация) на основе категорий закрытых значков.
