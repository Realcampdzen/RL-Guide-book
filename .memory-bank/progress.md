## Accepted UX (не менять без явной задачи)
- **Реальный Дневник — базовая реализация (ОБЯЗАТЕЛЬНО СОХРАНЯТЬ):**
  - Сетка «Что было за день»: **Утро**, **День**, **Вечер**, **Чем запомнился день** — каждая секция с полем текста и выбором эмодзи (DiaryRow).
  - Блок «Рефлексия»: Что было важным сегодня? / О ком из друзей хочется записать? / Какие выводы сделал за день?
  - Данные: `morningText`, `morningEmoji`, `dayText`, `dayEmoji`, `eveningText`, `eveningEmoji`, `memorableText`, `memorableEmoji` в `diaryProgress.entries`; плюс `mainMoments`, `friends`, `conclusions`.
  - Реализация принята, нравится заказчику. При развитии дневника этот функционал не терять.
- **Всплывашка «О концепции игры» (главная):** открытие по наведению на кнопку; закрытие по клику вне, по уходу курсора со всплывашки, по клику по области карточки (не по кнопкам «Поделиться»/«Создать Движок»); после закрытия по клику по карточке повторное открытие по ховеру блокируется до ухода курсора с кнопки и нового наведения. Позиция от триггера (getBoundingClientRect), ширина до 720px, стрелка к триггеру. Поведение зафиксировано, доработки не требуются.
  - **Как реализовано в коде** ([src/components/BlueNestLanding.tsx](../src/components/BlueNestLanding.tsx)): триггер — кнопка в обёртке с `ref={conceptWrapRef}` и `ref={conceptButtonRef}`; якорь — `conceptPopoverAnchor` + `conceptPopoverAnchorRef`, расчёт в `computeConceptPopoverAnchor()`, при открытии по клику/ховеру якорь пишется в ref и state до `setIsConceptOpen(true)` (без мерцания). Блокировка повторного открытия по ховеру: ref `conceptHoverSuppressedRef`; в `handleConceptPointerEnter` при `conceptHoverSuppressedRef.current` — ранний return без открытия; при уходе с триггера — `handleTriggerPointerLeave`: сброс флага и закрытие; при уходе со всплывашки — `handlePopoverPointerLeave`: только закрытие. Закрытие по клику по карточке: у span всплывашки `onClick` — если `(e.target as Element).closest('button, a')` не сработал, то `setIsConceptOpen(false)` и `conceptHoverSuppressedRef.current = true`. Стили/стрелка — [src/styles/bluenest.css](../src/styles/bluenest.css): `.subtitle-hint`, `.subtitle-hint[data-placement='anchor'][data-anchor-side='above'|'below']::before`.
