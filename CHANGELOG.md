# Changelog

Все значимые изменения в проекте "Путеводитель Реального Лагеря" будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [2.5.0] - 2026-04-14
*Modernization Update / The Great Refactoring*

### Добавлено
- 🚀 **Стек Будущего** — полный переезд на React 19, TypeScript 6.0 и Vite 8.
- 🧹 **Code Quality** — внедрен Biome.js для глобального автоформатирования и линтинга.
- 📉 **Оптимизация Бандла** — удалены тяжелые JPG-исходники из git tracking'а, артефакт деплоя уменьшен почти в 10 раз (с 2.2GB до ~250MB), доставляются исключительно WebP-изображения.
- 📝 **Документация SSOT** — финальная актуализация всех дорожных карт (Roadmap 2026), перевод всех продуктовых модулей (M1-M17) в стабильный Production.

### Изменено
- 🛠 **Победа над Монолитами (Strangler Fig)** — успешное завершение 7-фазного рефакторинга: огромный `ProfileView` распилен на независимые доменные контейнеры.
- 🧩 **Единый DataContext** — ликвидация 'God Hook' (`useDataLoader.ts`) в пользу централизованного Singleton Провайдера (избавились от дублирования API-запросов и состояний гонки).
- 🎨 **Модульный CSS** — гигантский файл стилей профиля декомпозирован на 14 изолированных доменных CSS-модулей, ликвидировано глобальное "протекание" стилей (CSS bleed).

### Исправлено
- 📱 **Мобильная Стабилизация (iOS/Safari)** — устранены критические краши GPU-рендеринга («black screen flash» и «checkerboard») из-за агрессивных `backdrop-filter`.
- 📐 **Геометрия Viewport** — переход на единицы `svh` и `100lvh` избавил мобильный интерфейс от "скачков" при скролле системной адресной строки браузера.
- ⚡ **FPS и Layer Thrashing** — убраны конфликты динамических `box-shadow` и анимаций, добавлены аппаратные ускорения `will-change: transform` для безупречной 60FPS плавности чатбота.

## [2.0.0] - 2026-04-13
*Cloud & Social Edition / BigTech Agent Framework*

### Добавлено
- ☁️ **Облачная Архитектура** — полная миграция данных с локального JSON на базу данных Supabase (PostgreSQL) с продакшен-деплоем на Vercel.
- 🛡️ **Гибкая Ролевая Модель (RBAC)** — 5 уровней (Участник, Вожатый, Педагог, Родитель, Девелопер) через полноценную JWT авторизацию со строгим доступом (Server-side).
- 🎉 **Social & Viral Центр (AAA)** — "Share Center", генерирующий "вирусные" брендированные изображения прогресса, сгенерированные ИИ-мотивационные вызовы в форматах 9:16 и 16:9.
- 🎨 **ИИ-Генерация Визуала** — возможность создавать гербы "Движков", обложки "Крыл" и персональные кастомные арты значков напрямую из ЛК.
- 🚀 **Интеграция с Мессенджерами (Webhooks)** — Webhook-слушатели для Telegram и ВКонтакте, автоматические уведомления и система тикетов для заявок на значки.
- 👔 **Умные Кабинеты** — новые пространства: "Совет Лагеря", "Штаб Крыла", "Реальный Отряд", "Кабинет Педагога".
- 💼 **Оркестрация и ИИ Агенты (AgentOS)** — внедрена методология Agent Orchestration: BigTech роли (SRE, SWE), "Memory Bank" и децентрализованный Claim Board для слаженной мульти-агентной работы.

### Изменено
- 🔐 **Безопасность API** — все эндпоинты защищены, добавлены строгие rate-limits (IP и DeviceId) против флуда и ботов. 429 и 5xx ошибки обрабатываются на уровне UI с подсказками.
- 💅 **UI/UX Личного Кабинета** — единая капсула "Spaceship Dashboard", скролл-анимации, консистентные empty states.
- ⚙️ **Производительность** — slim-сериализация для легкого `localStorage`, E2E Grid для QA-тестирования (Playwright), и оффлайн-кэш для "Идей сообщества".
