# Промпты в cf-api (копии для справки)

**Источник истины:** [chatbot/prompts/](../../chatbot/prompts/) в корне репозитория.

Файлы в этой папке не используются в рантайме cf-api. Чат-промпт и факты синхронизируются в `cf-api/src/neurovalyusha/` скриптом из корня:

```bash
npm run sync:cf-api-prompts
```

При изменении промптов или facts.json править нужно в `chatbot/prompts/`, затем запустить синхронизацию.
